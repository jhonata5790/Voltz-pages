# Main

Pontos de entrada responsáveis por inicializar cada página ou modo do jogo.

Estrutura planejada:

- `game-main.js`: inicialização do mundo aberto, NPCs, reinos e batalha.
- `auth-main.js`: inicialização da tela de login e cadastro.
- `openworld-test-main.js`: inicialização isolada do mapa de testes.

Esses arquivos devem apenas conectar os módulos; regras de jogo não devem ficar aqui.
