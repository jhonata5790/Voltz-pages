# NPC

Módulos responsáveis pelos personagens não jogáveis e suas interações.

Estrutura planejada:

- `npc-data.js`: dados, posições, retratos e falas dos NPCs.
- `npc-renderer.js`: criação visual dos NPCs no mapa.
- `dialogue-system.js`: abertura, avanço e encerramento de diálogos.
- `npc-interactions.js`: distância de interação e ações especiais.

Os dados e comportamentos serão retirados gradualmente de `assets/js/openworld.js`.
