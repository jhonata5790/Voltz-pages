# Realms

Módulos responsáveis pelos Reinos do Conhecimento.

Estrutura planejada:

- `realm-data.js`: nomes, matérias, estados de desbloqueio e configurações.
- `realm-panel.js`: interface de seleção dos reinos.
- `realm-navigation.js`: entrada, saída e troca entre mapas.
- `math-realm.js`: configuração inicial do Reino da Matemática.

O sistema atual continuará funcionando enquanto a migração for feita por etapas.
