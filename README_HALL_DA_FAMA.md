# Hall da Fama

A antiga Central de Ranking agora é um interior completo.

## Ranking único
1. Conclusões completas do jogo
2. Diplomas conquistados
3. XP

O ranking real vem do Supabase. O banco mantém uma tabela pública de ranking
contendo apenas nome público, conclusões, diplomas e XP; inventário e progresso
detalhado continuam protegidos no perfil.

O campo `_world.gameCompletions` já está previsto para quando o final dos cinco
reinos existir. Até lá, todos começam com 0 conclusões.

Entre no Hall da Fama, fale com o Curador e termine o diálogo para abrir o Registro Global.
