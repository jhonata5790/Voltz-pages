# UI ampliada e inventário

Esta versão adiciona:

- viewport do mundo aberto ocupando praticamente toda a área abaixo da barra superior;
- HUD contextual de Matemática ocultada automaticamente durante batalhas;
- inventário de mundo aberto acessível por `I` ou pelo botão `Mochila [I]`;
- itens persistentes exibidos no inventário;
- diplomas e competências permanentes exibidos separadamente;
- Dica de Foco continua sendo consumida somente dentro da batalha;
- inventário é atualizado automaticamente após alterações no perfil/Supabase.

## Atalhos

- `I`: abrir/fechar Mochila no mundo aberto;
- `Esc`: fechar Mochila;
- `E`: interagir;
- `P` + `menu`: Painel Dev.

O inventário não abre durante batalhas para evitar conflito com a Mochila de combate.
