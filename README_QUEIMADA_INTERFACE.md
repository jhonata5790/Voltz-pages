# Queimada — Interface tática

A Queimada recebeu uma interface nova inspirada na sensação de batalha por turnos:

- menu base com **ARREMESSAR / TÁTICA / ITEM / POSTURA**;
- caixa de diálogo em estilo batalha;
- Capitão Rubro como rival fixo da arena;
- submenus de arremesso, tática, item e postura;
- turno inimigo com padrões nomeados de esquiva;
- atalhos de teclado:
  - `1` a `4` para escolher opções;
  - `0` ou `Backspace` para voltar;
  - `Espaço` para lançar no medidor;
  - `WASD/Setas` na fase de esquiva.

TÁTICA, ITEM e POSTURA já têm efeitos básicos reais para o duelo.
