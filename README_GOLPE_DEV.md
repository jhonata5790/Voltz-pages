# Golpe DEV de batalha

Abra o painel secreto normalmente:

1. Pressione `P`
2. Digite `menu`
3. Na seção **Batalha · sessão**, use:
   - **Golpe DEV −100 PV**
   - **Curar jogador**

O timer continua pausado enquanto o Painel Dev está aberto.

## Segurança da progressão

O Golpe DEV reutiliza a lógica real da batalha:

- inimigo comum com 0 PV → vitória normal;
- Ortcepse/Espectro → progressão normal;
- Espectro → Diploma de Português normalmente;
- Golem → para no limite de 50% e inicia o reconhecimento do guardião;
- não existe recompensa extra específica do cheat.

A cura é somente de sessão e não é salva.
